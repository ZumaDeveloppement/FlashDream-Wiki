
# 🎮・Commandes du Serveur

📢 **Commandes Utilisables sur le Serveur Naruto RP**

### 📝 Commandes écrites

* **@Modération** → Envoyer un message aux modérateurs
* **/me** → Décrire une action ou une description
* **/pm** → Message privé envoyé à la personne ciblée
* **/give** → Donner de l'argent
* **/dropmoney** → Poser de l'argent
* **/ad** → Décrire une action importante à la narration
* **/ad N/A** → Décrire une action importante *hors RP* (scène spéciale)
* **((** → Envoyer un message *hors RP* (local)
* **/fac** → Envoyer un message à sa faction
* **//** → Envoyer un message en **OOC** (visible par tout le serveur)

***

### 🎮 Commandes actions

* **F1** → Inventaire
* **F2** → Menu Général
* **F3** → Activer la souris en premier plan
* **F4** → Menu Animations
* **F10** → Ouvrir l'invite de commande
* **ALT + E (regarder vers le bas)** → S'asseoir
* **CTRL + ESPACE** → Sauter plus haut
* **C** → Ouvrir le menu
* **Y** → Ouvrir le chat

***

### 📌 Touches et raccourcis complets

Ci-dessous, l'ensemble des touches, commandes et raccourcis disponibles sur le serveur. N'hésitez pas à les consulter afin de profiter pleinement des différentes fonctionnalités mises à votre disposition.

**Menus (F) :**

* **F1** → Inventaire
* **F2** → Menu bind, rolls, skill
* **F3** → Mode curseur
* **F4** → Menu animation
* **F7** → Menu escouade
* **F8** → Changer de perso
* **F9** → Duels

**Actions et déplacements :**

* **A** → Esquive
* **E** → Interaction
* **R** → Recharge de chakra
* **O** → Accepter une escouade
* **P** → Refuser escouade
* **F** → Parade
* **G** → Déposer la personne
* **H** → Changer le mode volume
* **L** → Menu OST
* **M** → Map
* **C + CLIC DROIT** → Porter une personne
* **B** → Zoomer
* **SHIFT** → Courir vite
* **CTRL** → S'accroupir
* **CTRL + ESPACE** → Saut de chakra (mode jutsu)
* **MOLETTE** → Changer de mode (jutsu, caméra, main libre...)
